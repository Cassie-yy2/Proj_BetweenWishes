心愿之间 | Wish Between
A little wish, a lovely surprise. 💗
心愿之间是一款面向情侣的心愿清单与惊喜送礼 Web 应用。双方可以分别记录自己想要的礼物，并在需要送礼时，通过随机抽选为对方准备惊喜。
产品希望解决一个小问题：既想让伴侣知道自己喜欢什么，又不想让送礼变成提前公布答案的任务。
✨ Features
- Personal Wishlists — Each partner maintains an independent wishlist.
- Surprise Gifting — Randomly draw a wish when preparing a gift, keeping other wishes secret.
- Priority-based Selection — Prioritize high-priority wishes before medium- and low-priority ones.
- Budget Matching — Set a budget to help select suitable gifts.
- Occasion Reminders — Keep track of birthdays, anniversaries, and other special occasions.
- Gift History — Track gift selections and gifting progress.

💡 Product Principles
1. Keep wishes personal — Each user manages their own wishlist.
2. Keep surprises secret — A recipient should not see specific gift details before the appropriate time.
3. Make gifting intentional — Budget, priorities, and special occasions help make gift selection easier.
4. Start simple, iterate continuously — Prioritize a usable core experience before adding complexity.
